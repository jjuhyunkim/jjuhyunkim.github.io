# Methylation analysis using long-reads

## Introduction
가지고 있는 dataset이 2 sample은 HiFi 이고, 3 sample은 ONT라서 align은 `Winnowmap`으로 진행을 했지만, Methylation calling 부터는 다른 tool로 진행했었다. HiFi는 `pb-cpg-tools`로, ONT는 `modkit`으로. 그런데 결과를 비교하다가 보니까, ONT 결과에서 Methylation calling이 더 많이 나온 것을 확인할 수 있었고, 그 이유가 무엇인지 한번 더 살펴보려고 한다. 


## DNA modifications
* Dinucleotide 조합에 따라
  * CpG : C와 G base 사이에, 즉 C에 methylation이 되어 있는 경우. (mammalian genome에서 95% 이상이 CpG dinucleotide에서 발생)
  * CpH (where H = A, C, or T) : methylated C 다음에 G가 아닌 다른 base가 오는 경우
* Methyl기가 붙는 위치에 따라
  * 5mC (5-methylcytosine) : DNA methyltransferase (DNMTs)에 의해 생성. Generally repressive marker.
  * 5hmC (5-hydroxymethlcytosine) : Ten-eleven translocation (TET) enzyme이 5mC를 oxidize해서 생성. Active marker.

## HiFi and `pb-cpg-tools`
![Figure1](https://www.pacb.com/wp-content/uploads/kinetics.png)

* HiFi sequencing 동안에 CpG인지와 관계없이 모든 modification을 detect함. 
* `pb-CpG-tools`는 Pacbio에서 개발된 tool로 only 5mC methylation의 probability를 계산.
* 기존에 train된 calling 모델을 사용할 경우에는 CpG sites에서만 계산함.
* Strand를 고려하지만 report 할때에는 forward에 merge 해서 result를 냄. 

## ONT and `modkit`
![Figure2](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcRfh53MlmAc9aQXZ8sm9PkyINMuSHFYnVhC46ZWpXSHtesPYidW4iLQruI&s=10)

* ONT도 HiFi sequencing 과 마찬가지로, 어떤 base 인지는 상관 없이 modification을 detect함. 
* `modkit`은 Oxford Nanopore Technoilogies에서 개발된 tool로, 다양한 context(사용자가 motif를 줄 수 있음. ex. `--motif GATC 1`)와 다양한 modification (5mC, 5hmC, 6mA 등)을 detect 할 수 있음. 
* Strand를 고려하고, default는 forward strand에 있는 CpG와 reverse strand에 있는 GpC를 다르게 report함. 하지만 `--combine-strands`라는 parameter로 merge가능. 
* 즉, `pb-CpG-tools` 결과와 비교하려면, 아래 parameter를 함께 써야함. 하지만, CpG 처럼 반대편 strand에서 symmetric 하지 않다면 (ex CHH..etc), `--combine-strand`는 쓰지 않아야 함.
  ```bash
  modkit pileup \
    --cpg \
    --combine-strands
  ```

  | Location |Strand | methylated | coverage |
  | ------ | ------ | ---------: | -------: |
  | 0 |+      |      48/50 |      96% |
  | 1 | -      |      47/49 |      96% |

  이라면, merge 후에는

  | Location |strand    | methylated | coverage |
  | ------ | ------ | ------ | ----- |
  | 0 | + |      95/99 |      96% |

  coverage가 늘어나므로 통계적으로 더 안정적.

# Methylation analysis using long-reads

## Introduction
In the dataset I have, two samples are HiFi and three samples are ONT, so alignment
was done with Winnowmap, but from methylation calling onward, different tools were used.
For HiFi, pb-cpg-tools was used, and for ONT, modkit was used. While comparing the
results, I found that more methylation calling results were obtained from ONT, and I want
to take another look at why that happens.

## Basic

### DNA modifications
* Depending on dinucleotide combinations
  * CpG: when methylation is on C between C and G bases.
    (In mammalian genomes, more than 95% occurs at CpG dinucleotides.)
  * CpH (where H = A, C, or T): when a base other than G follows methylated C
* Depending on where the methyl group is attached
  * 5mC (5-methylcytosine): generated by DNA methyltransferases (DNMTs). Generally a repressive marker.
  * 5hmC (5-hydroxymethylcytosine): generated when Ten-eleven translocation (TET) enzymes oxidize 5mC. An active marker.

### HiFi and `pb-cpg-tools`

![Figure1](https://www.pacb.com/wp-content/uploads/kinetics.png)

* During HiFi sequencing, all modifications are detected regardless of whether they are at CpG sites.
* `pb-CpG-tools` is a tool developed by PacBio and calculates the probability of only 5mC methylation.
* When using a pre-trained calling model, calculation is performed only at CpG sites.
* It considers strand information, but reports results merged to the forward strand.

### ONT and `modkit`

![Figure2](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcRfh53MlmAc9aQXZ8sm9PkyINMuSHFYnVhC46ZWpXSHtesPYidW4iLQruI&s=10)

* Like HiFi sequencing, ONT also detects modifications regardless of which base they are on.
* `modkit` is a tool developed by Oxford Nanopore Technologies and can detect various contexts
  (the user can provide motifs, e.g., `--motif GATC 1`) and various modifications (5mC, 5hmC, 6mA, etc.).
* It considers strand information, and by default reports CpG on the forward strand and GpC on the reverse strand separately.
  However, they can be merged with the `--combine-strands` parameter.
* In other words, to compare with `pb-CpG-tools` results, the following parameters should be used together.
  ```bash
  modkit pileup \
    --cpg \
    --combine-strands
  ```
